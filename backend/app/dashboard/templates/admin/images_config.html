Invisible Watermark (TrustMark)

Every generated image (both txt2img and img2img) is invisibly watermarked at the gateway using Adobe TrustMark — the Content Authenticity Initiative watermark. The mark is imperceptible, survives PNG/JPEG re-encoding, and can be verified by anyone with the open-source TrustMark decoder. Watermarking is fail-open: if encoding fails, the unmarked image is still returned.

At most {{ watermark_max_chars }} printable ASCII characters — TrustMark carries 61 bits of payload. Decodes back to exactly this string.
Content Policy (LLM-as-Judge)

Every image generation prompt is evaluated by an LLM against the policy below before the image is generated. If the policy field is empty, no LLM check is performed. The system is fail-closed: if the judge LLM is unavailable or returns an unexpected response, the image request is denied.

LLM that evaluates prompts against the policy.
Used if the primary judge is unavailable or errors.
Natural language policy. The judge LLM evaluates each prompt against this text. Leave empty to disable policy checks. Prompts are evaluated in a sandboxed context with prompt injection protections.
API Usage

OpenAI-compatible endpoint:

curl -X POST https://mindrouter.uidaho.edu/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "black-forest-labs/FLUX.2-dev",
    "prompt": "A mountain at sunset",
    "size": "1024x1024",
    "response_format": "b64_json"
  }'

Optional parameters:

  • n — number of images (max {{ max_n }})
  • size — dimensions (default: {{ default_size }})
  • num_inference_steps — quality steps (default: {{ default_steps }}, max: {{ max_steps }})
  • guidance_scale — prompt adherence (default: {{ default_guidance_scale }})
  • seed — reproducibility seed
  • response_format — url or b64_json
