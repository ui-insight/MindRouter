Telemetry

GPU, node, and backend readings, taken every few seconds. Raw readings stay in the app DB for Tier 1 days. When the archive DB is configured and Tier 2 is above 0, 5-minute averages (power, utilization, temperature, load) are written to the archive continuously and kept for Tier 2 days.

Manual Purge

Immediately remove records in one category older than a cutoff, using the same pipeline as the retention cycle: when an archive database is configured, requests/chat rows are archived before they leave the app database; file artifacts are removed with their rows. When telemetry Tier 2 is above 0, telemetry's 5-minute averages are brought up to date first, as far as the archive allows; the readings are deleted either way, so any the archive could not take (if it is unreachable, say), and the last ~10 minutes, are deleted without averages.

This cannot be undone. The admin audit log is never purged.

0 = purge everything in the category.
