Sampling Guard Rails

Per-model floor on temperature and cap on max_tokens, applied to every request after routing. Some RL-trained models (GLM 5.3, MiMo 2.6) loop until the token limit under greedy decoding; their vendors publish temperature 1.0 / top_p 0.95. A JSON object keyed by catalog model name, or "*" for all models: {"zai-org/glm-5.3-flash": {"min_temperature": 0.7, "max_tokens": 32768}}. Clamped requests are logged as sampling_policy_applied, never rejected. Leave empty to disable.

Decisions API (System One) Experimental

POST /v1/systemone (alias /v1/decisions) speaks TypeSafe's System One wire format (Jev): one shared state plus typed noul / choice / score questions in, typed answers with probabilities out. No text is generated. The request's model picks how answers are produced: a vLLM model below is scored by one-token letter likelihood on servers MindRouter already runs; an upstream server is a purpose-built decision model that is its own System One server (for example Laya). jev-latest means the default model. Off by default.

vLLM models only, per question type.
