# Dependency lock for the MindRouter image (app + mcp share it).
#
# Every pin here is a version that has RUN in production. pyproject.toml
# declares floors ("fastapi>=0.109"); this file turns them into exact
# versions so a build made next month installs the same packages as the
# build made today. The Dockerfile sets PIP_CONSTRAINT to this file, so pip
# may only choose versions listed here (a package absent from this file is
# still resolved freely; the test suite checks that every declared
# dependency is present).
#
# Why: on 2026-09-29 a routine rebuild resolved SQLAlchemy 2.1.1, released
# the week before, which no longer installs greenlet; the async engine could
# not import and alembic failed on the new image. Nothing in the repo had
# changed. See docs/index.md "Dependency lock".
#
# To upgrade a package: raise or change its floor in pyproject.toml if
# needed, then run `make lock` (builds the image, freezes the venv, rewrites
# this file) and commit the diff with the release that carries it.
#
# Provenance of each revision is in its commit message (image id, date,
# Python version); the first revision froze the mindrouter-app 2.9.77 venv.
